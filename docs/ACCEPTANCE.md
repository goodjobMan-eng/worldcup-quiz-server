# NATIONLAB 1차 프로토타입 검증

기준: [2026-10-09 첨부 요구서](SANDBOX_REQUIREMENTS.md). 이전 3개국·6라운드 모드의 검증과 구분합니다.

브라우저 검사에서 채굴·도구는 UI로 실행하고, 갤러리는 엔진 시뮬레이션이 실제 규칙으로 완성한 작품 데이터를 테스트용으로 주입합니다. UI만으로 수업 전체를 수동 진행했다는 의미는 아닙니다.

## 균형 시뮬레이션

`npm run simulate`는 자원 채집·체력 회복·가공·다리 기여·이웃을 통한 중계 교역·건축·등록을 실제 엔진 명령으로 실행합니다.

| 나라 | 교역 없음 등록 | 교역 있음 등록 | 완성 블록 | 교역 후 수입 재료 종류 |
| --- | --- | --- | --- | --- |
| 화련 | 불가 | 가능 | 15 | 4 |
| 히노미 | 불가 | 가능 | 14 | 4 |
| 사하르 | 불가 | 가능 | 14 | 3 |
| 루미나 | 불가 | 가능 | 15 | 5 |

두 경우 모두 시뮬레이션 경과 64분·2차시이며 이동·회의·협상·설명 시간을 제외합니다. 실제 수업 길이를 보장하는 결과가 아닙니다. 교역 없음 비교에서는 원래 닫혀 있는 2단계를 테스트 안에서만 열어 **재료 조건 자체도 만족할 수 없는지** 확인합니다. 학생 플레이에서는 이 잠금을 우회할 수 없습니다.

## 실시간 검증과 실제 교실의 차이

Auth·RTDB·Firestore 에뮬레이터와 독립 Chromium 컨텍스트로 교사 1명, 학생 5명의 입장·배정·채집 경쟁·계정 복귀·일시정지·삭제를 검사했습니다. 교사 인증은 에뮬레이터용 Google 제공자 토큰이며 실서비스 팝업 로그인은 별도 확인 대상입니다.

초기 측정에서 두 경쟁 요청의 처리 결과를 모두 받기까지 약 2.65초(최종 재검사 약 2.00초)가 걸렸습니다. 한 컴퓨터에서 6개 3D 화면을 동시에 실행한 값이며, **반영 1초 기준을 통과한 것으로 보지 않습니다.** 학생 요청 전 전체 상태 재조회와 이동 시 전체 방 구독을 제거했습니다. 위치는 별도 구독으로 제한하나 경제 행동은 아직 방 상태 트랜잭션이며 완전한 청크별 변화 전송 구조는 아닙니다.

교사 브라우저가 요청을 검증·처리하므로 계속 열어 두어야 합니다. 교사 종료 시 학생은 처리 대기 안내를 받고, 재접속한 교사가 추가 전용 요청과 처리 영수증으로 이어 처리합니다. 클라우드 함수는 사용하지 않습니다.

## 아직 완료로 판단하지 않은 기준

- 실제 Firebase 프로젝트의 Google 팝업 로그인, 승인 도메인, QR을 통한 물리 태블릿 접속.
- Galaxy Tab A 계열의 30fps, 초기 로딩 10초, 학생 간 반영·교사 일시정지 1초.
- 학생 40명, 여러 반 동시 접속, 수업 1주일 동안의 데이터 사용량과 Spark 한도.
- 일주일 수업을 통해 모든 학생이 배움을 설명할 수 있는지에 대한 교사 관찰.
- 항구와 다른 반 연결 승인·교역·갤러리, 대한민국 전체 학교 오픈월드(요구서 2차 범위).

## 교실 리허설 순서

1. 실제 프로젝트 설정·규칙을 적용하고 교사 1대, 학생 4~6대로 QR 입장합니다.
2. 같은 나라 학생 두 명이 한 자원을 동시에 캐어 복제·반영 시간·체력 변화를 확인합니다.
3. 양쪽 다리를 완성하고 제안 수정→양쪽 동의→교환을 진행합니다.
4. 기술자 파견과 귀국, 잠시 네트워크 끊김 후 복귀를 확인합니다.
5. 계획판을 함께 수정하고 다른 입체로 동일 투영을 만들어 등록합니다.
6. 교사가 승인한 작품의 개수를 예상하고 원산지·가공지를 확인합니다.
7. 성찰 CSV·전체 결과를 받은 뒤 방 삭제를 확인합니다.
8. 20명, 40명으로 늘려 지연·fps·용량을 측정한 뒤 본수업에 사용합니다.

## 지하 광산·원유 정제 추가 검사

광산 출입 거리와 지상/지하 행동 분리, 광석 채굴, 지하에서 지상 시설 사용 금지, 정제 기술 제한, 원유의 유리·철판 직접 사용 거부, 원유 산지와 중간 정제 나라 이력, 기존 방의 재고·대기시간을 유지하는 갱신을 엔진에서 검사합니다. RTDB 규칙은 학생이 출입 명령 없이 위치의 지상/지하 값을 바꾸는 것을 거부합니다.

`node scripts/mine-browser.cjs`는 준비된 위치에서 실제 키 이동으로 입구 통과, 지하 조준·채굴, 지하 새로고침, 출구 통과, 가방 유지까지 검사합니다. 위치·곡괭이를 테스트용으로 준비하며, 섬 전체를 걸어 탐험한 시험과 구분합니다.
